CryptoX — Secure Messaging Platform

A full-stack encrypted messaging application designed with a security-first architecture and deployed to production on Amazon Web Services. CryptoX implements hardened user authentication flows, session management, and lightweight persistent storage, demonstrating the integration of security controls across the full application lifecycle — from local development to cloud-hosted deployment.

Python Flask SQLite AWS EC2 HTML5 / CSS3 / JS
  • Real-time, session-isolated messaging with server-side validation on all inputs
  • Hardened user authentication with scrypt password hashing and secure session management
  • Hybrid encryption architecture using AES-256-GCM for message confidentiality and RSA-OAEP for secure key exchange
  • Digital signature verification using RSA-PSS to ensure message authenticity and integrity
  • Support for encrypted direct messaging, private group conversations, encrypted file transfer, and voice messaging
  • Secure VPN infrastructure using WireGuard for encrypted network tunneling and protected communication channels
  • Cloud deployment on AWS with environment-separated configuration management
  • Applied security engineering principles including confidentiality, integrity, authentication, secure key management, and defense-in-depth

Project 02
VoxKey — Continuous Behavioral Authentication

A multi-modal, continuous authentication system that transcends the limitations of static login-time verification. VoxKey monitors user identity across an entire active session by fusing two complementary behavioral biometric signals — voice biometrics and keystroke dynamics — to construct a persistent, evolving identity fingerprint. Unlike conventional authentication, the system can detect identity anomalies mid-session and enforce re-verification automatically, significantly reducing the attack surface of compromised credential scenarios.

React TypeScript Python Flask SQLite Web Audio API
  • Voice biometrics module — extracts speaker-specific acoustic features using MFCC analysis for identity verification via microphone input
  • Keystroke dynamics engine — profiles user typing cadence, dwell time, and inter-key latency to build a behavioral fingerprint
  • Session-continuous verification — identity is validated throughout the session, not only at the authentication boundary
  • Anomaly-triggered re-authentication — behavioral drift beyond a defined threshold prompts step-up verification

Project 03
Document Search Engine — Indexed Information Retrieval

A high-throughput document indexing and search system built on Elasticsearch, exposing a clean RESTful backend API for query processing. The system supports full-text indexing across heterogeneous document corpora, applies relevance-scored ranking to results, and is instrumented with Kibana for operational monitoring and query analytics. It integrates JWT authentication to secure API access and enforce stateless, token-based user authorization. Designed with extensibility in mind, it provides a reusable foundation for security-relevant retrieval applications such as audit log querying and policy document search.

Python Elasticsearch Kibana REST API
  • Full-text document indexing with field-level mapping and tokenisation configuration
  • BM25 relevance-ranked search results via the Elasticsearch scoring engine
  • RESTful backend API for structured query submission, JWT-based authentication, and result pagination
  • Secure stateless user authorization using JSON Web Tokens (JWT)
  • Kibana dashboard integration for search analytics and index health monitoring

Project 04
PC-Agent — Local AI Desktop Assistant

A modular AI desktop assistant powered by Ollama and Llama 3.2, designed to understand natural language instructions and autonomously execute actions on a local machine. PC-Agent combines conversational AI, intent recognition, and tool-calling mechanisms to bridge human language with system-level task execution. The assistant processes requests locally through on-device inference, enabling privacy-preserving interactions without dependence on external cloud APIs. Its architecture emphasizes extensibility, lightweight orchestration, and secure local automation for intelligent desktop control.

Python Ollama Llama 3.2 Local AI JSON Tool Calling Desktop Automation
  • Natural language command interpretation using local LLM inference through Ollama and Llama 3.2
  • JSON-based tool-calling architecture enabling autonomous execution of desktop and web actions
  • Automated task execution including application launching, website navigation, YouTube search, file creation, and program execution
  • Conversational memory and intent recognition for context-aware interactions across user sessions
  • Privacy-focused local inference pipeline eliminating dependency on external cloud AI APIs
  • Modular and extensible agent architecture designed for scalable AI-assisted desktop workflows
