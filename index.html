VoxKey Continuous Behavioral Authentication
The Problem How to continuously verify a user's identity during a session using behavioral characteristics such as voice and typing patterns.

A multi-modal, continuous authentication system that transcends the limitations of static login-time verification. VoxKey monitors user identity across an entire active session by fusing two complementary behavioral biometric signals voice biometrics and keystroke dynamics to construct a persistent, evolving identity fingerprint. Unlike conventional authentication, the system can detect identity anomalies mid-session and enforce re-verification automatically, significantly reducing the attack surface of compromised credential scenarios.

React TypeScript Python Flask SQLite Web Audio API
  • Voice biometrics module extracts speaker-specific acoustic features using MFCC analysis for identity verification via microphone input
  • Keystroke dynamics engine profiles user typing cadence, dwell time, and inter-key latency to build a behavioral fingerprint
  • Session-continuous verification identity is validated throughout the session, not only at the authentication boundary
  • Anomaly-triggered re-authentication behavioral drift beyond a defined threshold prompts step-up verification

Document Search Engine Indexed Information Retrieval
The Problem How to efficiently index and search a growing collection of documents when traditional search methods become less suitable for large-scale data.

A high-throughput document indexing and search system built with Java and Spring Boot, integrated with Elasticsearch for full-text search. Exposes a clean RESTful API for query processing, applies BM25 relevance-scored ranking, and uses JWT authentication for secure, stateless API access.

Java Spring Boot Elasticsearch Kibana REST API
  • Full-text document indexing with field-level mapping and tokenisation configuration
  • BM25 relevance-ranked search results via the Elasticsearch scoring engine
  • Fault-tolerant fuzzy search to handle spelling errors and minor query inaccuracies
  • Query optimization to improve search efficiency and response performance
  • RESTful backend API for structured query submission, JWT-based authentication, and result pagination
  • Role-Based Access Control (RBAC) to restrict document access according to user roles and authorization levels
  • Secure stateless user authorization using JSON Web Tokens (JWT)
  • Kibana used externally to inspect and visualize indexed data and monitor index health

Project 05
Try Prototype ✦
FROG Compiler for a Fictional Language
The Problem How to design and implement a complete compiler pipeline — from lexical analysis to AST generation — for a custom programming language, and expose it through an interactive GUI.

A fully functional compiler for FROG, a structured fictional programming language designed to illustrate core compilation principles. The compiler performs lexical analysis, recursive-descent parsing, and semantic analysis, then generates a visual Abstract Syntax Tree (AST) via Graphviz. A Qt5 desktop interface provides an interactive environment to write, compile, and inspect FROG programs in real time.

Python Qt5 Graphviz Compiler Design
  • Lexer — tokenises FROG source code into a typed token stream for downstream processing
  • Recursive-descent parser — builds a parse tree from the token stream following the formal FROG grammar
  • Semantic analyser — validates declarations, type consistency, and variable usage across the program
  • AST visualisation — generates a graphical syntax tree via Graphviz to aid debugging and comprehension
  • Language features: typed variable declaration (FRG_INT, FRG_REAL, FRG_STRG), assignment, FRG_Print output, IF/ELSE conditionals, and REPEAT/UNTIL loops
  • Qt5 desktop frontend — interactive editor with compile-on-demand and integrated AST viewer
